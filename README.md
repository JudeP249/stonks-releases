# STONKS for Mac

Downloads for the STONKS portfolio tracker. This page holds only the finished app. There's no code here and no one's data.

## Download

Go to the **[latest release](https://github.com/JudeP249/stonks-releases/releases/latest)** and download the file for your Mac:

| Your Mac | Download |
|---|---|
| Apple chip (M1, M2, M3, M4…) | `STONKS-x.y.z-arm64.dmg` |
| Intel processor | `STONKS-x.y.z-x64.dmg` |

Not sure which you have? Apple menu → **About This Mac**. It says either "Chip: Apple M…" or "Processor: …Intel…".

## Install

1. Open the downloaded file and drag **STONKS** onto **Applications**.
2. Open STONKS from Applications. Your Mac will say it can't check the app for malicious software, because STONKS isn't sold through Apple. Click **Done**.
3. Open **System Settings → Privacy & Security**, scroll down to *"STONKS" was blocked*, click **Open Anyway**, and confirm.

You only do this once. After that, STONKS updates itself: when a new version is ready, a bar at the top of the app says **Restart to update**.

Your data stays on your own Mac.
